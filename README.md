# Minerva Admissions Platform

A web app to help applicants to Minerva University apply as authentically and articulately as possible. Built by Praise Vincent, M29, Buenos Aires rotation, April 2026.

## Live Site

[your-username].github.io/minerva-admissions

## Tech Stack

Vanilla HTML5, CSS3, JavaScript. Hosted on GitHub Pages. No frameworks, no build steps, no cost.

## Features

- Multi-step application form with auto-save
- Signal Not Noise: Socratic accomplishment articulation tool
- Verification Ledger: competition result verification system
- Freddy: spring-physics animated cat cursor companion
- Mood engine: 5 site themes with persistent preferences
